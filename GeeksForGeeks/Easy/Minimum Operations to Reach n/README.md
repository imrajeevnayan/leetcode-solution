<h2><a href="https://www.geeksforgeeks.org/problems/find-optimum-operation4504/1">Minimum Operations to Reach n</a></h2><h3>Difficulty Level: Easy</h3><hr><p><span style="font-size: 18px;">Given a number <strong>n</strong>. Find the minimum number of operations required to reach <strong>n</strong> starting from <strong>0</strong>. </span></p>
<p><span style="font-size: 18px;">You have two<strong> </strong>operations available:</span></p>
<ul>
<li><span style="font-size: 18px;">Double the number </span></li>
<li><span style="font-size: 18px;">Add one to the number</span></li>
</ul>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 8
<strong>Output:</strong> 4
<strong>Explanation</strong>: 0 + 1 = 1 <strong>--&gt;</strong> 1 + 1 = 2 <strong>--&gt;</strong> 2 * 2 = 4 <strong>--&gt;</strong> 4 * 2 = 8.
</span></pre>
<pre><span style="font-size: 18px;"><strong>Input</strong>: n = 7
<strong>Output:</strong> 5
<strong>Explanation</strong>: 0 + 1 = 1 <strong>--&gt;</strong> 1 + 1 = 2 <strong>--&gt;</strong> 1 + 2 = 3 <strong>--&gt;</strong> 3 * 2 = 6 <strong>--&gt;</strong> 6 + 1 = 7.</span></pre>
