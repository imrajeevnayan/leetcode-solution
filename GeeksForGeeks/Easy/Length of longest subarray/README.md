<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [2, 3, 4, -1, -2, 1, 5, 6, 3]
<strong>Output: </strong>4

<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 0, 0, 1, -1, -1, 0, 0, 1, 0]
<strong>Output: </strong>4
<strong>Explanation: </strong>The subarrays [1, 0, 0, 1] and [0, 0, 1, 0] both have the maximum length 4 and contain no negative integers. Hence, the answer is 4.
</span></pre>
